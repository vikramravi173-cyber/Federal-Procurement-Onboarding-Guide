# Federal Procurement Onboarding Guide

A multi-step interactive guide to help small businesses navigate the federal contracting process.

## Features

- **10-step walkthrough** covering registration, certifications, and bidding
- **Progress bar** with step-by-step navigation
- **Check off completed steps** — progress saved in your browser
- **Plain-English explanations** with links to official government resources
- **"Why this matters"** callouts on every step

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
npm run preview
```

## Tech Stack

- React 19 + TypeScript
- Vite
